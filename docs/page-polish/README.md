# 整页视觉整理

围绕圆润的云上小岛，统一界面的纸张质感、图标和操作层次。

- 标题区区分前缀与主标题，增加信封标记和细线；邮戳入口明确标注“信箱 · 集章”。
- 桌面漫游工具采用同一组描边图标和纸面托盘，支持悬停与键盘焦点提示。
- 四季与时间合并为相邻的控制区；时间入口直接显示当前时刻，详细面板向上展开。
- 寄信按钮更突出，写信窗口加入航空信封边饰和信纸横线。
- 夜间使用柔和的深紫纸面，并调整次要文字、指南按钮与滚动条的对比度。
- 手机底部合并为紧凑的两行操作区；漫游工具默认收起，选取工具后自动收起，为岛屿保留更多画面。
- 页脚文案随四季变化，冬季不再始终显示“春天，还很长”。
